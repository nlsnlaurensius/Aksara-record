# AKSARA Recorder Web

Versi aktif AKSARA Recorder berada di folder ini. Petunjuk penggunaan, struktur ZIP, privasi, penggantian video pertanyaan, dan cara deploy dijelaskan di [README utama](../README.md).

Perintah pengembangan:

```powershell
npm install
npm run dev
```

Perintah pemeriksaan dan build:

```powershell
npm run check
npm test
npm run build
```

Hasil produksi berada di folder `dist` dan harus disajikan melalui HTTPS agar kamera serta mikrofon dapat digunakan pada perangkat partisipan.
